## Supabase CLI

This project uses Supabase. Install the CLI using one of these methods:

**macOS (Homebrew) — recommended:**
```bash
brew install supabase/tap/supabase
```
> Requires up-to-date Xcode Command Line Tools. If brew fails, run `sudo xcode-select --install` first.

**Direct binary download (no brew required):**
```bash
# Apple Silicon
curl -Lo supabase.tar.gz https://github.com/supabase/cli/releases/latest/download/supabase_darwin_arm64.tar.gz

# Intel Mac
curl -Lo supabase.tar.gz https://github.com/supabase/cli/releases/latest/download/supabase_darwin_amd64.tar.gz

tar -xvf supabase.tar.gz && sudo mv supabase /usr/local/bin/supabase
```

**Without installing (via npx):**
```bash
npx supabase <command>
```

> Note: `npm install -g supabase` is **not supported** by the Supabase CLI.
