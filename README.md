## Getting Started

1. Run `npm install`
2. Copy `.env.example` to `.env.local` and fill in your Supabase keys
3. Run `npm run dev` (serves on http://localhost:5173)

## Deployment

The site is hosted on Vercel and serves production from https://actreflectconsult.com.

- **Production**: pushes to `main` deploy to https://actreflectconsult.com.
- **Dev / preview**: every pull request gets an automatic Vercel preview URL. Use those for review and QA — there is no separate `dev.` subdomain.
- **Local**: `npm run dev` on http://localhost:5173.

### One-time domain setup (Vercel + registrar)

1. **Vercel** → Project → Settings → Domains → add `actreflectconsult.com` and `www.actreflectconsult.com`. Vercel will show the DNS records to create.
2. **Registrar DNS** → add the records Vercel shows. Typically:
   - Apex `actreflectconsult.com` → A record `76.76.21.21`
   - `www` → CNAME `cname.vercel-dns.com`
   - SSL certificates are issued automatically once DNS resolves.
3. **Supabase** → Authentication → URL Configuration:
   - **Site URL**: `https://actreflectconsult.com`
   - **Additional Redirect URLs** (one per line):
     - `https://actreflectconsult.com/**`
     - `https://www.actreflectconsult.com/**`
     - `https://*.vercel.app/**` (so PR preview deploys can sign in)
     - `http://localhost:5173/**` (local dev)
4. **Vercel env vars** → confirm `VITE_SUPABASE_URL` and `VITE_SUPABASE_ANON_KEY` are set for both Production and Preview environments.
